# 🧮 BMI Calculator

A simple beginner-level JavaScript project that calculates Body Mass Index (BMI) based on user input and shows the result with visual feedback.

## 📌 Project Description
This project allows users to enter their height and weight to calculate their BMI.
After calculation, the BMI score is displayed along with a background color that represents the BMI category.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ⚙️ How It Works
1. User enters height (in cm) and weight (in kg)
2. Clicks the calculate button
3. BMI is calculated using the standard formula  
   `BMI = weight / (height × height)`
4. Result is displayed with a color indicator

## 🎨 BMI Categories
- **Underweight**: BMI < 18.6 (Yellow)
- **Normal**: BMI 18.6 – 24.9 (Green)
- **Overweight**: BMI > 24.9 (Red)
